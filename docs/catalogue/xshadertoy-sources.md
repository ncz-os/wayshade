# xshadertoy: the thirty shaders in detail

The Shadertoy-API family, one row per shipped shader with the author, the
licence as recorded in the shader's own header, and the source link. The
page that describes the family is
[xshadertoy.md](xshadertoy.md).

## Credits

`docs/PROVENANCE.tsv` is the machine-readable record of the same facts:
one row per saver with its origin, licence, attribution, source path and
the commit that decided it. `NOTICES.md` is the prose version, and
`debian/copyright` the machine-readable DEP-5 one. Where a licence could
not be established from the shader's own header it is recorded as unknown
rather than guessed.
